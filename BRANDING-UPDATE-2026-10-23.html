REMOTE HUSTLE — branding update

The existing layout now uses royal blue #215FFC, white, pale blue #F2F6FF and ink #01040D. Cyan #24C1FD and violet #672FFC support the logo. Yellow #F4D35E remains an optional accent token. UI gradients have been replaced with solid fills; photographic panels retain a uniform dark overlay for legibility.

Included

Transparent full logo and a separate symbol in public/brand. The header and footer use the symbol with readable uppercase text. The favicon endpoint uses the same symbol. Existing admin-uploaded logos still take precedence: clear an older custom logo in admin branding settings if you want the bundled default.

Install

Merge this source into your project, keeping your own .env.local. Run npm install, npm run build, then redeploy. This branding update adds no environment variables or database migrations. Earlier search/FAQ features still require migrations 016 and 017 if you have not applied them.

Favicons may remain cached in browsers and search results after deployment.

Assets

Prepared using the built-in image editor from your supplied logo, with transparent background enabled. Edit direction: preserve the unicorn/R silhouette; remove background; use blue, cyan and violet; produce an isolated symbol for small sizes. Raster assets are included; retain your original master for future vector or print work.

Validation

TypeScript and all 108 automated tests passed. Production build and HTTP asset checks were also run. Interactive browser visual verification was unavailable in this environment; review mobile and desktop appearance before deploying to production.
